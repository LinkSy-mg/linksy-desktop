# Security

Linksy can share the screen, take input, run a terminal and move files between devices,
so security problems matter a lot here.

## Reporting a problem

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/LinkSy-mg/linksy-desktop/security/advisories/new).

Include what an attacker needs (same network, a paired device, the relay, local access)
and how to reproduce it. You'll get an answer within a few days, and credit in the release
notes if you want it.

## Supported versions

Only the latest release gets fixes. The phone app is in
[linksy-mobile](https://github.com/LinkSy-mg/linksy-mobile); report its problems the same
way there, or here if unsure.
